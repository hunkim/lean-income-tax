# 소득세법 원문 수집 기록

기준일은 2026-09-06이다. 국가법령정보센터의 [현재 소득세법](https://law.go.kr/법령/소득세법) 연결이 가리키는 **시행 2026-07-01, 법률 제21221호, 2025-12-23 일부개정, lsiSeq 280405** 통합본을 `data/corpus.json`으로 고정했다. 공포일이 더 최근인 2026-04-21판만으로 현재 판을 선택하지 않았다. 7월 시행판에는 2026-04-21 개정사항도 통합되어 있으며, 예컨대 제59조의2에서 해당 개정주석을 확인할 수 있다.

- [현재 고정 원문](https://law.go.kr/LSW/lsInfoP.do?lsiSeq=280405&efYd=20260701&ancYnChk=0&chrClsCd=010202): 본문 325개 조문, 현존 258개, 삭제 67개, 부칙 115개.
- [과거 2026-04-21판](https://law.go.kr/LSW/lsInfoP.do?lsiSeq=285523&efYd=20260421&ancYnChk=0&chrClsCd=010202): `data/historical-20260421.json`.
- [별도 2027-01-01 시행판](https://law.go.kr/LSW/lsInfoP.do?lsiSeq=280405&efYd=20270101&ancYnChk=0&chrClsCd=010202): `data/future-20270101.json`, 본문 326개 조문. 현재판 계산에 섞지 않는다. 이 목록이 가능한 모든 장래 개정의 완전한 목록이라는 주장은 하지 않는다.

원본 HTML과 가져온 시각·URL·SHA-256은 `data/sources/`에 보존했다. 세 판에 포함된 본문 이미지 37종도 별도 보존하고 SHA-256을 기록했다. 현재판에는 이미지 참조 36개가 있다. 본문 HTML의 모든 조문 선택 항목, 부칙 선택 항목, 조문별 텍스트가 파싱 결과에 대응함을 검사했다. 원래 제1조~제177조의 기본 번호 누락과 중복 ID도 검사했다. 이는 원문 수집의 구조 검사이며 법적 해석 또는 수학적 형식화 검증이 아니다.

## 이미지 수식과 표의 한계

단순 `get_text()`는 이미지로 실린 공식 세율표·수식을 버린다. 따라서 `text`에는 `[공식 이미지 대체텍스트: ...]`로 원래 alt를 넣고, `images` 배열에 실제 원본 URL과 저장 경로를 함께 기록한다. **alt 자체가 항상 원본 이미지와 같지는 않다.** 다음 두 문제를 확인했다.

1. **제55조제1항:** 공식 이미지 alt는 10억원 초과 행에서 누적기초세액 `3억8,406만원`을 누락한다. 실제 [공식 표 이미지](https://law.go.kr/LSW/flDownload.do?flSeq=123278409)를 직접 열어 해당 금액을 확인했다. 검증 데모에 쓰는 전사표는 `data/article55-rates.json`이다. 원본 alt를 몰래 수정하지 않고 전사본과 불일치 이유를 별도로 보존했다. 이는 **법문 자체의 비엄밀성이 아니라 웹 대체텍스트의 결함**이다.
2. **제35조:** 공식 alt가 `img151111067`이라는 파일 식별자뿐이다. 이미지 원본은 저장했으나 수식 전사·해석은 아직 검토하지 않았다.

제55조 이외 35개 현재판 이미지 참조의 의미 정확성을 검토 완료했다고 주장하지 않는다. 원문을 보여줄 때 이미지도 인라인으로 표시해야 한다.

## 제55조제1항 데모 입력 표

단위는 원이다. 첫 행을 제외한 하한은 초과, 상한은 이하이며 마지막 상한은 없다. 계산식은 `기초세액 + (과세표준 - 하한) × 세율 / 100`이다.

| 하한 | 상한 | 기초세액 | 세율 |
|---:|---:|---:|---:|
|0|14,000,000|0|6%|
|14,000,000|50,000,000|840,000|15%|
|50,000,000|88,000,000|6,240,000|24%|
|88,000,000|150,000,000|15,360,000|35%|
|150,000,000|300,000,000|37,060,000|38%|
|300,000,000|500,000,000|94,060,000|40%|
|500,000,000|1,000,000,000|174,060,000|42%|
|1,000,000,000|상한 없음|384,060,000|45%|

과세표준이 이미 확정되었다는 조건 아래의 표이다. 총급여로부터 과세표준을 산출하는 규칙, 각종 공제·감면, 원천징수, 기납부세액, 끝수처리, 귀속연도별 적용례를 포함하지 않는다. 이 표만으로 연말정산 결과나 환급액을 계산할 수 없다.

## 검토 상태와 재현

`data/classification.json`은 현존 조문 전부를 `pending`, 원문 검토 상태를 `unreviewed`로 기록한 최초 목록이다. 이를 수학적으로 정의할 수 없는 조문의 판정으로 읽어서는 안 된다. 개별 조문의 부분 구현이나 협업 검토는 별도 증거를 갖추어 갱신해야 한다.

Python 3 및 beautifulsoup4를 설치한 뒤 다음 명령으로 재현한다.

```sh
python3 scripts/import_source.py --offline
```

오프라인 재현은 저장 원문과 이미지 SHA-256을 대조하고 동일 구조를 다시 파싱한다. `--offline`을 생략하면 같은 고정 판 URL에서 다시 가져온다. 시행령·시행규칙·조세특례제한법·국세기본법·판례는 이 원문 묶음에 포함되지 않는다. 부칙에는 적용례가 존재하므로 본문 시행일과 개별 과세기간의 적용 여부를 동일시하지 않아야 한다.
