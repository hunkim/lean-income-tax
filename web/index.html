01 · A SMALL VERIFIED STEP

과세표준이 1원 늘면, 세금은?

법률·세무 검토가 아닌, Lean 모델의 활용 예시입니다.

제55조 제1항의 기본 세율표만 계산합니다. 총급여·연봉을 과세표준으로 대신 넣을 수 없습니다. 공제·감면·기납부세액·지방소득세를 반영한 납부·환급액이 아닙니다.

  1. 총급여 → 소득금액
    공제·비과세 미구현
  2. 소득금액 → 과세표준
    자격·공제 미구현
  3. 과세표준 → 기본 산출세액
    이번에 검증한 수치 부분
  4. 결정세액 → 정산 차액
    세액공제·기납부액 미구현

확정된 과세표준으로 실험

0~1조 원의 정수. 입력은 서버로 전송하거나 저장하지 않습니다.

정확한 수학적 값은 원의 1/100까지 표시합니다. 법정 끝수처리는 아직 적용하지 않습니다.

경계값에서 생기는 차이

1,400만 원을 입력한 뒤 결과를 확인해 보세요. 다음 1원에 적용되는 세율과 전체 금액에 적용되는 세율은 다릅니다.

무엇을 증명했나요?

단조성: 기본 모델에서 과세표준이 커지면 산출세액이 줄지 않습니다.

증가분 상한: 기본 세액 증가분은 과세표준 증가분의 45% 이하입니다. 공제·지원금을 포함한 실수령액 전체의 성질은 아닙니다.

일반 정리는 자연수 전체에 대한 증명입니다. 브라우저 계산은 별도의 JavaScript 구현이며, 개별 입력마다 Lean 커널을 실행하지 않습니다.

03 · QUESTIONS FOR FURTHER REVIEW
더 명확히 하거나 구현할 부분
입법자·연구자가 확인할 질문입니다. 미구현을 법문 결함으로 단정하지 않습니다.
[T1] 외부 사실·적용 요건
거주자 해당성과 종합소득과세표준을 외부에서 확정합니다. 어떤 소득을 합산하고 어떤 공제를 적용하는지는 이 함수가 판단하지 않습니다.
검토 질문: 적용 자격과 계산 입력의 근거를 어떤 조문·증빙으로 추적할 수 있을까요?
[T2] 미구현 계산 단계
공제·감면·기납부액·지방소득세·끝수처리 및 귀속연도별 적용례를 연결해야 연말정산으로 확장할 수 있습니다.
검토 질문: 본법·시행령·다른 법률의 계산 순서를 재현 가능한 형태로 연결할 수 있을까요?
[T3] 증명 적용 한계
기본 세율표의 단조성은 공제·지원금·자격 변동을 포함한 최종 부담이나 실수령액의 단조성을 뜻하지 않습니다.
검토 질문: 추가 규칙을 결합했을 때 어떤 경계에서 결과가 달라질까요?
[T4] 원문의 표·이미지
법령에는 이미지로 제공되는 수식·세율표가 있습니다. 대체 텍스트와 원본 이미지가 다를 수 있어 원본을 함께 보존합니다. 제55조 표도 이미지와 대조합니다.
검토 질문: 사람이 읽는 표와 기계가 읽는 수치 데이터를 동일하게 제공할 수 있을까요?
