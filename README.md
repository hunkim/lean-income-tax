# 소득세법 / in Lean

소득세법 전체 조문의 형식화 가능성 지도와, 2025년 귀속 일반 근로소득자의 공제·정산 수치 모형입니다. 법률·세무 자문이나 신고·환급 확정 서비스가 아닙니다.

## 실행과 재현

```sh
python3 scripts/verify_lean.py
npm run build
npm run dev
# http://localhost:4174
```

Node22+, Python3, Lean4.33.1이 필요합니다. `lean/lean-toolchain`으로 버전을 고정합니다. 비표준 설치 경로는 `LEAN_BIN_DIR`로 지정합니다. `python3 scripts/import_source.py --offline`은 보존 원문을 재현하며 beautifulsoup4가 필요합니다. `python3 scripts/classify_finalize.py`는 저장된 공동 검토에서 분류·근거·해시를 다시 검사합니다.

## 원문과 버전

기준일2026-09-06의 소득세법 통합본(시행2026-07-01, 법률21221호)을 전체 지도로 사용합니다. 본문325개와 부칙115개, 과거·미래 통합본, 원본 HTML·이미지·해시를 보존합니다. 통합본 내부의 개별 미래 시행문구도 별도 적용일 판단이 필요합니다. 연말정산 수치 모형은 이 지도 날짜 대신 별도2025귀속 국세청 안내서·정오표를 기준으로 합니다.

공식 제55조 세율표의 HTML 대체텍스트에는 최고구간 기초세액 누락이 있어 원본 이미지와 대조했습니다. `data/article55-rates.json`과 `reports/source.md`에 기록합니다. 다른 이미지 수식은 대부분 시각 검토 대기이며 alt만으로 전체 내용을 검증했다고 주장하지 않습니다.

원문·수학적 정의·정리·공동 검토·외부 전제는 웹에서 인라인으로 읽습니다. 하단 미해결 목록은 입법 검토를 돕는 자료이며 법문 결함이나 개정 필요성의 확정 판정이 아닙니다.

## 2025년 귀속 확장 (현재)

전체325개 조문의 형식화 가능성 분류를 마쳤습니다. 현존258개는 실제 SolarPro4 원문검토와 근거·해시 검증을 거쳤고, Astra는25개를 추가 개별 감사했습니다. 직접45·조건부155·구조57·현재미형식화1·삭제67입니다. 동일한 깊이의 전체 이중심사나 전체 Lean 구현을 뜻하지 않습니다. 조문 속 개별 미래 시행문구와 이미지 미검증도 남깁니다.

2025 귀속 국세청 안내서·정오표를 별도 보존해 총급여→근로소득공제→인적·연금·선택한 특별·카드 등 소득공제→과세표준→산출세액→주요 세액공제→결정세액→추가납부/환급 방향까지 연결했습니다. 2026년 시행 지도와 계산 귀속연도를 혼합하지 않습니다.

자동 수치 계산은 근로소득공제·기본/추가인적공제·근로소득세액공제·연금계좌·보험료·교육비·월세·자녀/출산입양·혼인·신용카드와 표준세액공제를 포함합니다. 자격·증빙·중복 여부는 외부 확인입니다. 의료비·기부금·복잡한 주택공제는 별도 확인한 당해연도 적격 순액을 입력합니다. 다른 소득·세액감면·외국인 단일세율·외국납부세액·지방소득세·농특세·이월·추징은 지원하지 않습니다. 그러한 사례는 결과를 확대 적용하지 않습니다.

영수증 금액 칸의 원 미만 절사를 구현했습니다. 보험과 연금의 서로 다른 공제 칸은 각각 절사하고 교육비는 사람별 한도 후 합계 칸에서 절사합니다. 근로세액공제 한도는 차액식을 계산한 뒤 절사합니다. 양의 차감징수액1,000원 미만의 소액부징수와 음의 환급을 구별합니다. 개인 결정세액을 일괄10원 단위로 절사하지 않습니다.

전체37개 Lean 정리의 의존성을 감사합니다. `reports/verification.json`에 기본세율25개 및 공제 구성요소·공제한도·카드·합성 정산의 실제 Lean 실행을 저장하고 JS 구현과 대조합니다. 국세청 안내서의 총급여6,540만원 사례도 독립 회귀로 확인합니다. 웹상 모든 입력을 새로 커널에서 실행하는 서비스는 아닙니다.

원문과 수학모형의 일치는 별도 검토입니다. Solar가 작성한 정산 정리는 구체적 전술·문법 안내 후 채택했으며 최초 실패와 안내 수준을 숨기지 않습니다. 최종 규칙대조 응답의 부정확한 지적도 Astra가 원문·산술로 판별해 별도 보존합니다.
