# 소득세법 / in Lean

대한민국 소득세법 전체 원문 지도와 근로소득·연말정산 계산의 작은 검증 데모. 독립 프로젝트 `lean-income-tax`입니다.

## 첫 구현

- 기준일 2026-09-06, 본문 시행 2026-07-01, 법률 제21221호의 공식 통합본. 본문 325개(현존258·삭제67), 부칙115개를 수집했습니다. 과거·미래 통합본은 분리합니다.
- 제55조 제1항의 8개 기본 세율 구간을 Lean4.33.1로 정의했습니다. 과세표준과 적용 자격은 외부에서 확정한 입력입니다.
- 자연수 과세표준 전체에 대해 기본 세액의 단조성과 증가분 45% 상한을 증명합니다. 정확한 세액의100배를 자연수로 표현하므로 소수점 오차·끝수처리를 섞지 않습니다.
- SolarPro4의 실제 작성·실패·도구 안내 후 성공과 수치 검토를 `reports/solar`에 보존합니다. 첫 구간 공동 정의의 일치도 Lean으로 증명합니다.
- 웹은 구간별 누적 기여액을 BigInt로 계산합니다. 모든 경계 전후를 포함한25개 Lean 실행 결과와 대조합니다. 웹의 모든 입력을 새로 커널에서 증명하지는 않습니다.
- 전체 조문의 의미 분류는 대기 상태입니다. 제55조 일부의 구현을 전체 소득세법 또는 연말정산 검증 완료로 표시하지 않습니다.

## 실행과 재현

```sh
python3 scripts/verify_lean.py
npm run build
npm run dev
# http://localhost:4174
```

Node22+, Python3, Lean4.33.1이 필요합니다. Lean은 `lean/lean-toolchain`으로 고정합니다. 로컬 비표준 경로라면 `LEAN_BIN_DIR`을 지정합니다. 원문 재수집에는 beautifulsoup4가 필요하며 `python3 scripts/import_source.py --offline`으로 저장 원문을 재현할 수 있습니다.

## 범위와 다음 단계

이 프로젝트는 법률·세무 자문이나 신고·환급 서비스가 아닙니다. 총급여→근로소득금액→과세표준→산출세액→결정세액→정산으로 확장하되, 현재는 기본 산출세액 수치 부분만 구현합니다. 귀속연도 적용례·공제 자격·시행령·조세특례·증빙·기납부액·지방소득세·끝수처리는 별도 연구 대상입니다.

원문, 표 이미지, Lean 정의·정리, 검증 결과는 웹에서 인라인으로 읽습니다. 하단에는 외부 판단과 미구현을 모아 입법 검토 질문으로 제시합니다. 기계화하지 못했다는 사실만으로 법문 결함이나 개정 필요성을 확정하지 않습니다.

공식 제55조 이미지의 대체 텍스트에는 최고구간 기초세액 누락이 있습니다. 이미지 전사와 이 발견의 근거는 `data/article55-rates.json` 및 `reports/source.md`에 기록합니다.
